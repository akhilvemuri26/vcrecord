Scope

Review conclusions

  • Shared capture and practice behavior: the dedicated test entry point uses the existing camera, MediaRecorder, and recognition PCM pipeline. Only test mode selects immediate recording and a five-second duration. Practice retains its validation, 15-second preparation/20-second answer defaults, preparation gating, and Stop & save behavior.
  • Cancellation and stale callbacks: setup cancellation races retain late permission-grant cleanup. Active tests discard recorder output on stop, abort, hidden page, pagehide, or track loss. Cancellation also resolves a pending PCM flush and suppresses final completion. UI generation checks protect close/retest/navigation transitions, and cleanup releases tracks, the audio graph, timers, and listeners. Closing clears playback and revokes its object URL.
  • Ephemeral sample: test completion creates only an in-memory playback URL and diagnostic text. It has no save, answer enqueue, or upload call. New practice closes the test before setup, and existing unsaved-answer protection prevents a new test. Sharing and rescue implementation remain unchanged.
  • Recognition diagnostics: missing PCM, exact-zero input, empty recognized text, and recognition errors remain distinguishable. Nonzero quiet or brief audio reaches Whisper rather than the former RMS threshold. Existing silent records receive neutral fallback wording, while existing status/storage schemas remain compatible.
  • Interface: preview is muted; playback has controls and is not audibly autoplayed. The PCM meter is labeled without a live announcement stream. Phase/result text is announced separately. Opening and closing manage focus, and the reviewed mobile screenshot shows a readable panel without horizontal clipping.
