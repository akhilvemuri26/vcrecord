Capture setup cancellation

src/capture.ts installs visibility and pagehide handlers before requesting camera/microphone access. A lifecycle event during setup permanently cancels that attempt, immediately stops acquired media tracks, disconnects any audio nodes and closes the audio context. Every asynchronous setup completion checks cancellation and current visibility before proceeding. Returning to a visible page cannot restart the cancelled attempt. Permission requests cannot be revoked by this API; if a pending permission request later returns a stream, it is stopped before preview or recording begins. Ordinary active recording still stops and saves a partial answer on hiding.

Transcript draft preservation

src/main.ts snapshots transcript text and its input revision when Save is clicked. IndexedDB writes that snapshot. Successful completion clears the dirty marker only when both revision and content remain unchanged. Newer input stays visible and dirty through the library refresh, with an explicit unsaved-changes status. A deleted answer is not reported as saved.
